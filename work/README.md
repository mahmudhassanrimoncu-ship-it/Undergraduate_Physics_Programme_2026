# Submitted work

Put each submission in `work/<semester>/<course>/<item>/`. For example:

```
work/S01-2027-spring/PHY101/pset01/pset01.pdf
work/S01-2027-spring/CMP101/a03/a03.ipynb
work/S02-2027-summer/LAB101/E1-pendulum/report.pdf
work/thesis/
```

Scans of handwritten work are fine. See the [Handbook §7](../docs/handbook.md).
